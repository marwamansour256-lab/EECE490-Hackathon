# Demo app

Open the pages directly in a browser; no server or internet is needed.

| Page | What it shows |
|---|---|
| `wejha.html` | Basket Growth: ranked add-on offers for a basket, display-layout comparisons and an editable profit scenario |
| `planner.html` | Preparation plan with the 16:00 top-up, Day explorer, Why tab, evidence on outside factors, and pilot log |

The `*_data.js` files are generated; rerun the script instead of editing them:

| File | Generated by |
|---|---|
| `recommendation_data.js` | `python src/basket_recommender.py train` |
| `wejha_data.js` | `python src/wejha_layout.py` |
| `preparation_data.js` | `python src/growth_plan.py --export-preparation` (uses the selected v2 preparation model) |
| `why_data.js` | `python src/why_drivers.py` |
| `evidence_data.js` | `python src/external_factor_test.py` |
| `day_data.js` | `python src/day_ledger.py` |

`check_ui.js` checks the frontend ranking logic and data contracts: `node app/check_ui.js`.
