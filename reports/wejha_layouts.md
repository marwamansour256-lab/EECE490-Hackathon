# Display-layout experiment

Layout hypothesis; incremental sales and customer paths unmeasured

**adjacent_pairs**: 0.3729 normalized weighted distance.

Banana Bread → Pistachio Cookie → Cinnamon Roll → Chocolate Croissant → Butter Croissant → Almond Croissant → Chocolate Cookie → Blueberry Muffin

**separated_pairs**: 0.5108 normalized weighted distance.

Butter Croissant → Cinnamon Roll → Blueberry Muffin → Banana Bread → Almond Croissant → Pistachio Cookie → Chocolate Cookie → Chocolate Croissant

**random_reference**: 0.4249 normalized weighted distance.

Cinnamon Roll → Blueberry Muffin → Banana Bread → Chocolate Croissant → Pistachio Cookie → Almond Croissant → Butter Croissant → Chocolate Cookie

Higher distance is the proposed exposure mechanism, not a demonstrated profit objective. Pair weights measure existing co-purchases. Actual customer paths, current layout and offer acceptance are absent.
